# ROADMAP

## v0.1 (実装済み・この雛形)

- [x] XInput 記録: 専用スレッド、最大 2000Hz、QPC タイムスタンプ、生値ロスレス
- [x] .padtas バイナリ形式 (差分時刻 + 状態 12 バイト/フレーム)
- [x] セグメント方式のプロジェクト管理 (続き記録、全セグメント連結再生)
- [x] ViGEmBus 仮想 Xbox 360 コントローラーへの再生 (絶対期限・ドリフトなし)
- [x] Velopack + GitHub Releases によるアプリ内自動更新の組み込み
- [x] GitHub Actions: CI (ビルド+テスト) / タグ駆動リリース
- [x] Core テスト 12 件 (ロスレス記録、連結境界、形式ラウンドトリップ等)

## v0.2 (実装済み)

- [x] モダンなダークテーマ UI (角丸フラットボタン、パネルレイアウト)
- [x] コントローラー表示: 押したボタンが光り、スティックが倒した方向へ動き、LT/RT はバーで量を表示。記録中・再生中・待機中 (実機モニター) 全てで連動
- [x] セグメント削除 UI (選択削除 / 全削除、確認ダイアログ付き、ファイルごと削除)
- [x] アプリアイコン (exe / ウィンドウ / インストーラー)
- [x] (v0.3.0) ViGEmBus ドライバの自動導入: 未導入を検出し、公式 GitHub から取得 → SHA-256 照合 → UAC 昇格してサイレント実行 (ダメなら通常ウィザード)。再生ボタン押下時にも未導入ならその場で提案

## v0.4 (実装済み)

- [x] スタートメニュー検索対応: 起動時にショートカット (PadTAS.lnk) の不足を自己修復
- [x] 再生の読み戻し検証: 再生中に仮想コントローラーを読み戻して送出状態と照合し、結果と不一致の証跡をログに残す (同時入力落ちの切り分け)
- [x] 4000Hz / 8000Hz ポーリング対応 (CPU 1コア占有の注意表示付き)
