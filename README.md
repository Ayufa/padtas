# PadTAS

<img src="src/PadTas.App/Assets/app-icon.png" width="96" alt="PadTAS icon">

Windows 用の **コントローラー TAS (Tool-Assisted Speedrun) レコーダー**。
実コントローラーの操作を高精度に記録し、仮想コントローラーからそのまま再生する。

## 特徴

- **超高精度な記録**
  - 専用スレッドで最大 2000Hz ポーリング (既定 1000Hz)
  - 時刻は QueryPerformanceCounter (分解能 約100ns) で記録
  - スティック (int16) / トリガー (byte) は **生値をロスレス保存**。記録時にデッドゾーンや平滑化を一切かけない
  - スティックの 1 LSB の動きまで拾う (変化した瞬間だけを記録する方式)
- **続きからレコード (セグメント方式)**
  - 記録は「セグメント (テイク)」単位でプロジェクトに追加されていく
  - 途中で止めて、後から続きを録り足せる。再生時は全セグメントが 1 本に連結される
  - セグメントごとに別ファイル保存なので、途中で落ちても記録済み分は残る
- **ドリフトしない再生**
  - 各入力を「開始時刻 + 相対時刻」の絶対期限で送るため、長時間でもズレが累積しない
  - 再生は ViGEmBus の仮想 Xbox 360 コントローラーへ出力
- **見てわかる UI**
  - モダンなダークテーマ。コントローラーの図が現在の入力と連動し、押したボタンが光り、スティックが倒した方向へ動く (記録中・再生中・待機中すべて)
  - 記録した入力 (セグメント) はリストから選択削除 / 全削除できる
- **アプリ内アップデート**
  - Velopack + GitHub Releases 連携。起動時に新バージョンを確認し、アプリ内から差分ダウンロード → 再起動で適用

## 動作環境

- Windows 10 / 11 (x64)
- 入力: XInput 対応コントローラー (Xbox コントローラー等)
- 再生時: ViGEmBus ドライバ 1.22.0 が必要ですが、**アプリが未導入を検出して自動で導入します**
  (公式 GitHub から取得し SHA-256 照合後に実行。管理者許可ダイアログだけ手動で「はい」を押してください)
  - ※ ViGEmBus は開発終了済みですが、最終版は署名済みで Windows 10/11 で動作します。手動導入も可: [公式リリース](https://github.com/nefarius/ViGEmBus/releases)

## 使い方

1. 配布版 `PadTas-win-Setup.exe` (GitHub Releases) を実行してインストール
2. アプリを起動し、「フォルダを選ぶ」でプロジェクトフォルダを作る/開く
3. コントローラーを接続し、「● 記録開始」→ 操作 → 「■ 停止して保存」
   - 記録するたびにセグメントとして末尾に追加される (続きから何度でも録れる)
4. 「▶ 全セグメント再生」で仮想コントローラーから再生

## 開発

```powershell
# ビルド (要 .NET 8 SDK)
dotnet build PadTas.sln -c Release

# Core のテスト (記録のロスレス性 / セグメント連結などを検証)
dotnet run --project tests/PadTas.Core.Tests -c Release
```

構成:

| フォルダ | 内容 |
|---|---|
| `src/PadTas.Core` | 記録形式・セグメント連結・再生スケジューリング (OS 非依存、テスト対象) |
| `src/PadTas.App` | WPF 本体。XInput 記録、ViGEm 再生、Velopack 更新 |
| `docs/DESIGN.md` | 設計書 (精度の考え方と限界、データ形式、更新の仕組み) |
| `docs/ROADMAP.md` | 実装済み / 次にやること |

## リリース手順 (GitHub)

1. `src/PadTas.App/PadTas.App.csproj` の `<Version>` を上げる
2. `vX.Y.Z` タグを push する
3. GitHub Actions (`.github/workflows/release.yml`) が Windows でビルドし、
   Velopack パッケージを GitHub Release にアップロードする
4. インストール済みのアプリは次回起動時に更新を検知する

## 注意

- 再現精度の最終的な上限は「ゲーム側が入力を何 fps で読むか」と「コントローラー自体のポーリングレート」です。詳しくは `docs/DESIGN.md`。
- オンラインゲームでの TAS / 仮想コントローラーの使用は、そのゲームの規約に抵触する場合があります。オフラインや許可された環境で使ってください。
